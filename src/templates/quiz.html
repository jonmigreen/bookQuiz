Book Recommendation Quiz

1. Age Group (1 point)

Books are first filtered to match the selected age group. Only books matching the age group will be recommended.

2. Support Types (0.5 points per match, max 1 point)

Each matching support type adds 0.5 points to the score. For example:

  • 1 matching support type = 0.5 points
  • 2 matching support types = 1.0 points

3. Learning Style (1 point)

Books matching the selected learning style receive 1 point.

4. Diverse Communities (1 point)

If a specific community is selected, books representing that community receive 1 point. If no specific community is selected but diverse representation is desired, books with general representation receive 0.5 points.

Final Score Calculation

The total score is divided by 4.0 to normalize it to a 0-1 range (0-100%). For example:

  • Perfect match (4 points) = 100%
  • Good match (3 points) = 75%
  • Partial match (2 points) = 50%
